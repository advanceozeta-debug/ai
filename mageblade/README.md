# 은월의 마검사 — 캐릭터 리소스 + 액션 로그라이트 미리보기

★6 · 근접 공격형. 컨셉 시트의 **동작 그림만** 하나씩 분리해 64×96 픽셀 스프라이트로 규격화했어요.

- 게임 미리보기: `index.html` (이동 ←→/AD · 공격 J/Z · 스킬 K/X · 판정 보기 H · 터치 버튼)
- 동작 미리보기: `viewer.html` (동작별 재생, 프레임 전부, 기준점·바닥선, 좌우 반전, 투명 확인 배경)
- 움짤: `assets/mageblade/preview.gif`

## 파일
| 파일 | 내용 |
|---|---|
| `assets/mageblade/mageblade_sheet.png` | 512×576 RGBA, 8열×6행, 칸 64×96. 위에서부터 대기·달리기·공격·스킬·피격·쓰러짐 |
| `assets/mageblade/mageblade_sheet.json` | 칸 좌표, 프레임 수, 프레임당 ms, 반복/마지막 유지, 기준점 (32, 92), 보정 메모 |
| `assets/mageblade/frames/*.png` | 개별 프레임 25장 (각 64×96) |
| `assets/mageblade/effects/` | 투사체·장판·폭발 원본 1장 + 재생용 가로 띠 (캐릭터와 별도 레이어) |
| `config.js` | 재생 속도, 공격 판정 프레임·범위, 스킬, 능력치, 상태 우선순위 |
| `game.js` | 상태 관리, 판정, 이펙트 레이어, 정수 배율 렌더링 |
| `tools/` | 재현 스크립트: `cut_frames.py` → `fix_frames.py` → `build_sheet.py` → `cut_effects.py` → `verify.py` |

## 상태 규칙
쓰러짐(4) > 피격(3) > 공격·스킬(2) > 달리기·대기(0). 공격·스킬·피격 중에는 이동 입력이 애니메이션을 덮어쓰지 않고, 끝나면 이동 중이면 달리기, 아니면 대기로 돌아가요. 피격은 공격·스킬을 끊고, 쓰러짐은 마지막 프레임을 유지해요.

## 움직임
- 같은 동작 안의 프레임은 머리·상체 위치를 서로 맞춰서(대기 ±0.5px, 달리기 ±1px) 떨림·잔상처럼 보이지 않게 했어요.
- 대기는 어깨를 1px 내렸다 올리는 숨쉬기, 달리기는 걸음마다 몸이 오르내림, 공격은 뒤로 젖혔다가 앞으로 7px 내딛으며 베기, 스킬은 쏘는 순간 반동, 피격은 뒤로 젖혀짐 (`config.motion`).
- 맞았을 때 깜빡이는 효과 대신 0.09초 하얀 번쩍임만 써요.

## 판정과 그림은 따로
공격 판정은 `config.attack.hitbox`(3번째 프레임에만), 투사체·폭발 판정은 `config.skill.*.hitbox`. 이펙트 그림 크기(78×26, 76×60 등)와는 별개라 판정 보기(H)에서 빨간 상자(판정)와 파란 상자(그림 영역)로 구분돼요.
